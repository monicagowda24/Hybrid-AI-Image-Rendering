About HybridAI

Hybrid Generative AI Architecture

A text-and-sketch conditioned image rendering system designed to transform creative ideas into AI-generated visual content.

✦ Project Overview

HybridAI combines natural language prompts with visual guidance to create controlled AI-generated images.

Users can provide a text description, upload a reference image, or draw a sketch to guide the rendering process.

⚡ Rendering Workflow

1. Enter a text prompt

2. Add a reference image or sketch

3. Generate the image using AI

4. Evaluate image quality

5. Refine the generated image

⚙️ Technologies Used

Frontend: HTML, CSS and JavaScript

Backend: Python and FastAPI

AI: Stable Diffusion and ControlNet

Database: PostgreSQL

Security: JWT authentication and bcrypt

◆ Key Features

• Text-conditioned image generation

• Reference image conditioning

• Interactive sketch conditioning

• Image quality evaluation

• AI image refinement

• Generation history
